## 这本书

吧叽城是一座狗的城市。一只名叫毛毛的白猫乘快艇而来，它的眼睛有魔力——成年狗只要与它对视便俯首称臣，于是全城大狗臣服，推举它为猫王，转而欺凌小狗。

只有两个年幼的家伙免疫：流浪狗**吉吉**和流浪猫**咪咪**。它们从海滩逃亡、失去家园、楼顶栖身，到出海寻访毛毛的前主人雪珠博士，最终带回能唤醒理智的「智慧之花」，以种花而非战争的方式解除了整座城市的奴役。

全 33 回署名均为「◆洗阳羊」，系同一作者完整原创连载，从 2012 年增刊开篇到 2015 年第 5 期全文完，无中断、无换人。

## 关于顺序

33 回的排列依据两条证据，而非文件名或检索结果顺序：

1. **超星发现所载刊期与页码**（年份 / 期号 / pp.）
2. **正文首尾衔接**——该连载每回开头都会复述上回结尾的悬念场景，逐回比对可验证连续性

由此纠正了两处常见错序：

- 「海中朋友」在「海岸烈焰」之前（后者开头即「灰灰**继续**讲述」）
- 开篇「吧叽城与毛毛」应置于全书之首（2012 年增刊C1，5 页，为全部篇目中最长）

## 关于文字层（重要）

这份影印 PDF 自带的 OCR 文字层**质量极差，不可引用**。它会把整行识别成毫不相干的内容，例如把标题行

> 狗城猫王（大结局 一路平安）猫王失势

识别成

> 原著：[意] 比安卡·皮佐诺 缩写：王玮

由此曾误传该作为「意大利作品缩写改编」。**原图上该位置是标题，署名实为「◆洗阳羊」。** 同理，「猫王失势」也被误作「猫王先势」。

因此本站只提供影印原图，不提供文字版。凡涉及署名、标题、关键结论，请以影印图为准。
